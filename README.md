# 오늘 뭐하지? - 활동 추천 프로그램

여가 시간에 무엇을 할지 고민될 때, 사용자의 관심사(태그)에 따라 맞춤형 활동을 추천해주는 데스크톱 애플리케이션입니다.

## 주요 기능

*   **직관적인 GUI:** Tkinter를 사용하여 누구나 쉽게 사용할 수 있는 그래픽 인터페이스를 제공합니다.
*   **태그 기반 추천:** 원하는 태그를 클릭하여 관련 활동을 필터링할 수 있습니다.
*   **AND 연산 필터링:** 여러 태그를 선택하면, 선택된 모든 태그를 포함하는 활동만 추천하여 더욱 정확한 결과를 제공합니다. (예: '실내'와 '정적인' 태그를 모두 선택하면 두 특성을 모두 만족하는 활동을 보여줍니다.)
*   **간편한 데이터 관리:** `tags.json`과 `activities.json` 두 개의 파일로 태그와 활동 데이터를 관리하여, 사용자가 쉽게 목록을 수정하고 확장할 수 있습니다.

## 화면 구성

1.  **태그 목록 (화면 상단):** `tags.json` 파일에 정의된 모든 태그가 버튼 형태로 나열됩니다.
2.  **활동 목록 (화면 하단):** `activities.json` 파일에 정의된 활동들의 이름이 목록 형태로 표시됩니다.

## 사용 방법
- 프로그램을 시작하면 모든 활동이 목록에 표시됩니다.
- 상단의 태그 버튼을 클릭하면, 해당 버튼의 색상이 바뀌면서 '선택' 상태가 됩니다.
- 태그가 선택되면, 해당 태그를 포함하는 활동만 목록에 표시됩니다.
- 다시 한번 태그를 클릭하면 '선택 해제' 상태가 되며, 필터링 조건에서 제외됩니다.

## 실행 방법
**이용하기전 꼭 주어진 API키를 `map_template.html`의 39번째 줄 '키 가림'의 위치에 입력하세요**
프로젝트 디렉토리에서 다음 명령어를 실행하여 애플리케이션을 시작할 수 있습니다.

```bash
python3 main.py
```
